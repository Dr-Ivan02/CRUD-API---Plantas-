# CRUD de Plantas

API REST sencilla para gestionar plantas de interior (se utiliza Node.js + Express + SQLite).

## Requisitos

- Node.js 22.13 o superior

## Instalación

```bash
npm install
cp .env.example .env
```

## Uso

```bash
npm start
```

La API queda en `http://localhost:3000`. Para comprobarla: `GET /health`.
